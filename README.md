## Aim:
To Design a Basic Mobile and Web Layout for an Existing Case Study

## Algorithm:
Apply Gestalt principles to enhance mobile and web layout design. Incorporate UI elements and design patterns into the layouts. Develop interaction behaviors and usability principles for the designs. Create a brand logo using Canva, following styling and branding guidelines and include it with your layouts.
Start Figma and create a new design file.



1.Create the first frame as the Home Page with a greeting, search bar, food categories and popular restaurants.



2.Add restaurant details such as food images, ratings, prices and delivery time.



3.Create the second frame as the Restaurant Page with a search bar and restaurant filtering options.



4.Display restaurant names, food categories, ratings and prices using cards.



5.Create the third frame as the Cart Page to display selected food items.



6.Add quantity controls to increase or decrease food items.



7.Design the bill details section with item total, delivery fee, platform fee and total amount.



8.Add navigation bars and buttons to connect the three screens.



9.Save the Figma project. Stop.
